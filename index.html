Digital Payment Route Optimizer

When an online transaction is executed, payments travel through multiple possible routes: Customer ➔ Bank A ➔ Payment Gateway ➔ Bank B ➔ Merchant. This system evaluates interbank network graphs to select the most cost-effective and low-latency route in real time.

Evaluated Algorithms
1. Dijkstra's Shortest Path
Minimizes accumulated transaction fees (₹) and processing latency.
2. Greedy Approach
Selects the neighbor with the immediate lowest fee at each hop.
3. Breadth-First Search (BFS)
Discovers the most direct path requiring the fewest interbank hops.
